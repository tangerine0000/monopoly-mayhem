# Security Policy

## Reporting a Vulnerability

Please do **not** report security vulnerabilities through public GitHub issues.

Instead, please report them privately via GitHub's **Security Advisories**
("Report a vulnerability" under the **Security** tab of this repository) or
contact the repository owner directly.

Please include:
- A description of the vulnerability and its potential impact
- Steps to reproduce or a minimal proof of concept
- Any suggested remediation, if known

You can expect an acknowledgment within a few days and updates as the issue is
investigated and resolved.
